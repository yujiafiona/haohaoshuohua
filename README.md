# 好好说话 · AI 沟通助手

**给重要对话，留一点准备时间。**

好好说话是一个轻量的 AI 沟通练习室。你可以在汇报进展、协调工作、表达边界或与家人交流前，先打磨一句话；也可以选择一个场景，写下自己的表达，再获得反馈。

参考《非暴力沟通》《关键对话》的沟通方法，帮助你保留立场，把感受、需求和期待表达清楚。

[在线体验](http://47.100.53.93:3000/)

## 可以用它做什么

| 能力 | 使用方式 |
| --- | --- |
| 表达改写 | 写下原话，选择沟通对象和目的，获得更清楚、更有分寸的表达建议 |
| 补充背景 | 按需补充对方特点或事情背景，帮助 AI 理解上下文 |
| 场景练习 | 选择对象和场景 → 生成题目 → 写下表达 → 获得分段点评 |
| 表达分析 | 展开查看情绪强度、攻击性、共情度和清晰度的参考评分 |
| 一键复制 | 将建议带到实际沟通中，再调整成你自己的语气 |
| 成长记录 | 每次成功使用积累 5 点功德值，积分与等级保存在当前浏览器 |
| 演示体验 | 不配置模型密钥也可以了解流程，预设示例会明确标识 |

**沟通对象：**老板、同事、伴侣、父母、子女、朋友。

**沟通目的：**提需求与寻求支持、汇报进展与对齐预期、拒绝与表达边界、表达不满与讨论分歧、安慰与提供支持。

## 先试一次

### 帮我改写

1. 写下你准备说的话，或描述一下发生了什么。也可以点击情境示例开始。
2. 选择沟通对象，以及这次对话希望达成的目的。
3. 如有需要，补充对方特点或背景。
4. 点击「帮我好好说」，查看、调整并复制建议表达。

例如：

> 我手上的任务已经排满了，这个新需求为什么又要今天上线？

可以尝试把重点组织为：

> 我理解这个需求比较紧急。目前手上的任务已经排满，如果今天优先处理它，原定工作需要相应顺延。我们能先一起确认优先级和交付范围吗？

以上为表达示例，实际生成内容会随输入、场景和模型变化。

### 场景练习

1. 切换到「场景练习」，选择对象和场景。
2. 生成一道练习题，写一句你会实际说出口的话。
3. 获取「总体、亮点、可优化、关联原则」四段反馈。
4. 根据建议修改表达，或继续练习下一题。

当前题目保留出题时的对象、场景和背景。调整设置后，可以按新设置重新出题。

## 本地运行

按当前锁定依赖，使用 Node.js 20.9 或更高版本。

~~~bash
git clone https://github.com/yujiafiona/haohaoshuohua.git
cd haohaoshuohua
npm ci
npm run dev
~~~

打开 [http://localhost:3000](http://localhost:3000)。

不配置 API Key 时进入演示模式。演示内容是预设示例，用于了解流程，不会根据任意输入实时生成个性化结果。

## 启用真实 AI 生成

在项目根目录创建 `.env.local`，选择一个服务配置。

**DeepSeek**

~~~dotenv
DEEPSEEK_API_KEY=你的密钥
~~~

**OpenAI**

~~~dotenv
OPENAI_API_KEY=你的密钥
~~~

保存后重启应用。当前代码中的调用配置为：

| 环境变量 | 模型 | 行为 |
| --- | --- | --- |
| `DEEPSEEK_API_KEY` | `deepseek-chat` | 配置后优先使用 |
| `OPENAI_API_KEY` | `gpt-4.1-mini` | 未配置 DeepSeek 时使用 |
| 两项均未配置 | 预设示例 | 展示演示流程 |

模型调用在服务端完成。请将密钥保存在环境变量中，不要提交到仓库或写入前端代码。

## 部署

### Vercel

导入本仓库，使用 Next.js 框架配置，在项目环境变量中填写上述任意一种 API Key，再部署应用。修改环境变量后，需要重新部署以使配置生效。

### 自有服务器

准备 Node.js 运行环境，在服务器上的项目目录安装依赖、构建并启动：

~~~bash
npm ci
npm run build
npm run start
~~~

生产服务默认使用 3000 端口，可结合进程管理工具维持运行，并按自己的访问需求配置反向代理、HTTPS 与网络规则。

更新版本前保留现有环境配置。建议在新目录安装和构建，检查通过后再切换服务，同时保留上一版本，以便必要时恢复。

## 使用与数据说明

- AI 生成的表达是建议，请结合事实和自己的语气调整；评分仅作练习参考。
- 补充的对方特点用于当前请求，不是跨会话的长期角色记忆。
- 成长记录保存在当前浏览器，清除浏览器数据会重置。
- 启用真实生成时，原话、背景和练习内容会发送给所配置的模型服务。
- 默认不写入服务器提问记录；只有配置 `LOG_REQUESTS_PATH` 时才会记录相关请求。自行部署并启用记录时，请说明数据用途并限制访问权限。
- RAG 知识库、练习历史和打卡日历属于后续方向，当前版本未提供。

## 技术结构

- Next.js App Router + TypeScript
- React 与自定义 CSS
- 服务端调用 DeepSeek / OpenAI
- 表达改写支持流式显示
- 本地浏览器存储成长记录

主要代码位于：

~~~text
src/app/page.tsx             页面与交互
src/app/globals.css          界面样式
src/app/api/coach/route.ts   模型调用、改写与训练接口
~~~
